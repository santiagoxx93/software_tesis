Diccionario de Datos

Este documento detalla la estructura física de la Base de Datos Relacional del sistema (tipos de datos, longitudes y restricciones), cumpliendo con los estándares de ingeniería de software.

Tabla: users (Almacena Trabajadores, Recepcionistas y Especialistas)
Campo Tipo de Dato Longitud Restricción Descripción
id BIGINT 20 PK, AI Identificador único del usuario.
name VARCHAR 255 NOT NULL Nombre completo del trabajador.
email VARCHAR 255 UNIQUE, NOT NULL Correo electrónico (Usado para Login).
password VARCHAR 255 NOT NULL Contraseña encriptada (Hash Bcrypt).
dni VARCHAR 20 UNIQUE, NULL Cédula o documento de identidad.
telefono VARCHAR 20 NULL Número de contacto telefónico.
especialidad VARCHAR 255 NULL Especialidad médica (Solo para doctores).
Tabla: pacientes (Almacena la ficha demográfica)
Campo Tipo de Dato Longitud Restricción Descripción
id BIGINT 20 PK, AI Identificador único del paciente.
cedula VARCHAR 20 UNIQUE, NOT NULL Cédula de identidad.
nombres VARCHAR 100 NOT NULL Nombres del paciente.
apellidos VARCHAR 100 NOT NULL Apellidos del paciente.
fecha_nacimiento DATE - NOT NULL Fecha de nacimiento para cálculo de edad.
genero ENUM 'M','F','Otro' NOT NULL Género biológico o identidad.
telefono VARCHAR 20 NOT NULL Número de contacto telefónico.
direccion TEXT - NULL Lugar de residencia física.
antecedentes TEXT - NULL Alergias o condiciones preexistentes.
Tabla: citas (Gestión de turnos y agenda)
Campo Tipo de Dato Longitud Restricción Descripción
id BIGINT 20 PK, AI Identificador único de la cita.
paciente_id BIGINT 20 FK (pacientes) Paciente que reserva la cita.
especialista_id BIGINT 20 FK (users) Médico asignado para la atención.
fecha_cita DATE - NOT NULL Día programado para la consulta.
hora_inicio TIME - NOT NULL Hora de inicio del bloque de agenda.
hora_fin TIME - NOT NULL Hora de finalización del bloque.
estado ENUM 'Pendiente', 'Completada', 'Cancelada' DEFAULT 'Pendiente' Estatus actual del turno.
notas TEXT - NULL Motivo o anotación de la recepcionista.
Tabla: historias_clinicas (Evolución y registro médico)
Campo Tipo de Dato Longitud Restricción Descripción
id BIGINT 20 PK, AI Identificador único de la evolución.
paciente_id BIGINT 20 FK (pacientes) Dueño de la historia clínica.
especialista_id BIGINT 20 FK (users) Médico que realiza el registro.
cita_id BIGINT 20 FK (citas) Turno asociado a esta consulta.
motivo_consulta TEXT - NOT NULL Razón por la que asiste el paciente.
sintomas TEXT - NULL Cuadro sintomatológico (Anamnesis).
diagnostico TEXT - NOT NULL Conclusión médica del especialista.
plan_tratamiento TEXT - NOT NULL Receta médica o indicaciones a seguir.
observaciones TEXT - NULL Notas extra (ej. reposo, próxima cita).
fecha_registro DATETIME - NOT NULL Fecha y hora exacta de la redacción.

* Nota: PK = Llave Primaria (Primary Key), FK = Llave Foránea (Foreign Key), AI = Autoincrementable. Todas las tablas incluyen campos created_at y updated_at (TIMESTAMP) administrados automáticamente por el framework.
